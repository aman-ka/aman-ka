## Production Work

*Shipping and operating production systems — from architecture and APIs to deployment, scaling, and iteration.*

### Full-stack platform architecture
- Multi-app workspaces: SSR storefronts, admin/vendor portals, and modular **NestJS** APIs on **Next.js / React**
- Server-authoritative business logic with **PostgreSQL + Prisma**, API-layer **RBAC** (RolesGuard), and shared domain services
- CMS & content ops: page studio with blocks/SEO, S3-backed media, runtime branding, and DB-driven transactional email via **Resend**
- Catalog & fulfillment tooling: inventory, pricing, replenishment POs, order routing, and admin operations dashboards

### Payments, tax & commerce flows
- End-to-end **Stripe** checkout: PaymentIntents, Elements, webhooks, saved payment methods, and order finalization
- Server-side amount/tax reconciliation — no client-trusted totals
- **TaxCloud** integration for US sales tax: live estimates, address validation, and clear API/UI error handling

### AI / LLM systems in production
- **Claude API** coaching flows with context-aware prompts and **Redis** session management
- **OpenAI** Chat Completions & **Assistants API** for recommendations, transcript QA, and structured JSON outputs
- Conversational AI, speech-to-text mood analysis, and real-time simulation with low-latency scoring & feedback loops
- Prompt engineering, retry/deduplication pipelines, and admin analytics over AI-generated outputs

### Microservices, data & APIs
- **Node.js microservices** on **Azure Kubernetes (AKS)** with Service Bus and **KEDA** autoscaling
- **GraphQL** and **REST** APIs; **PostgreSQL**, **MongoDB**, **DynamoDB**, and **Redis** in polyglot data pipelines
- Background processing with **BullMQ** workers; concurrent user simulations and KPI measurement APIs at scale

### Cloud, DevOps & enterprise integrations
- **AWS**: Amplify, ECS Fargate, RDS, ElastiCache, S3/CloudFront — plus **Azure** AKS for multi-cloud production workloads
- **Microsoft Teams** embedding for enterprise SaaS; Bot Framework for in-context product delivery
- **Docker**, **Kubernetes**, **Kafka**, and CI/CD for reliable deploy-and-operate workflows
